# 友人簿 · 使用说明

## 这是什么
一个装在你自己电脑里的朋友记录本。打开网页就能用，所有数据都在这个文件夹里，不经过任何服务器。

## 文件夹结构

```
友人簿/
├── index.html          ← 应用入口，双击用 Chrome/Edge 打开
├── css/                ← 样式文件
├── js/                 ← 脚本文件
├── data/
│   └── friends.json    ← ★ 所有数据都在这一个文件里
├── PRD.md              ← 产品需求文档，改功能先看这里
└── README.md           ← 本文件
```

## 怎么打开
双击 `index.html`，用 **Chrome 或 Edge** 浏览器打开（别用 IE、别用微信内置浏览器）。

第一次打开时，浏览器会弹窗问"是否允许读取此文件夹"，**选允许**——这样应用才能直接读写 `data/friends.json`。

## 怎么备份
**整个 `友人簿` 文件夹复制一份**，扔到网盘/U盘/另一处硬盘，就完成备份了。

不用做任何"导出"操作——因为数据本来就在文件夹里。

## 怎么恢复
把旧的 `data/friends.json` 覆盖回来就行。

## 怎么改数据（懂点 JSON 才动）
用记事本/VS Code 打开 `data/friends.json`，里面是结构化数据。
- 想加朋友 → 照着 `friends` 数组里现有格式复制一段改
- 想删朋友 → 删掉对应那段
- 手滑改错了 → 从备份里复制回来

**不懂 JSON 就别直接改这个文件**，所有增删改都在网页里操作。

## 以后想加功能/改样式
直接改 `index.html`、`css/`、`js/` 里的文件。改完刷新浏览器就看到效果。
如果要大改，先动 `PRD.md` 里的需求描述，再动代码。

## 注意
- 这个应用跑在你自己电脑上，**手机暂时访问不到**。后续如果要在手机上用，可以再做一个网页部署版本，但那样数据就要走云端了。
- 推荐 Chrome / Edge 最新版，别的浏览器可能打不开文件读写功能。
